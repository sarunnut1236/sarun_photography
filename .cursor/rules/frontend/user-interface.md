Design a modern, minimal portfolio website for a photographer based in Bangkok who specializes in portrait and landscape photography. The website should showcase photography in a clean, elegant, and distraction-free way. Use large images, generous whitespace, subtle UI elements, and smooth interactions so the photos remain the main focus.

The site must be responsive and work well on desktop, tablet, and mobile devices. It must also be bilingual with English and Thai support. Include a language switcher (EN / TH) in the header. Use the font “Trirong” for the entire website to maintain elegant typography for both languages.

The website contains three main pages: Landing Page, Portrait Gallery Page, and Landscape Gallery Page.

Every page should include a header and footer. The header contains the photographer’s logo on the left and navigation links on the right: Home, Portrait, and Landscape. The header also includes the language switcher and a dark mode toggle.

The footer provides contact and hiring information. It should state that the photographer is based in Bangkok and available for portrait sessions. Provide links to Instagram and email. Clearly show the hiring rate: 2000 Thai Baht per portrait session.

The Landing Page introduces the photographer. At the top there should be a hero section with a large featured photo and a short introduction describing the photographer’s passion, experience, and tools. Mention that the photographer is based in Bangkok.

Below the introduction, include a Portrait Photography preview section containing three carousels. Each carousel represents one portrait album from a photoshoot or event. Users can swipe left or right and the carousel rotates automatically. Each image in the carousel must have a description shown below the photo.

Below this section include a “Find More” button linking to the Portrait Gallery page.

Next include a Landscape preview section using a three-column Instagram-style grid. Each photo sits inside a square container. If the photo is not 1:1 ratio, scale it proportionally to fit inside the square while keeping transparent space around it. Show a “Find More” button linking to the Landscape Gallery page.

The Portrait Gallery page shows multiple portrait albums as carousels. Each carousel contains photos from one session and each image has a description below it.

The Landscape Gallery page shows a large three-column photo grid. Each image displays its description when the user hovers over it.

Support dark mode using this palette: background #121212, primary text #E0E0E0, secondary text #B0B0B0, borders #444444, accent #888888. Light mode should invert the concept with a light background and dark text while keeping a minimal aesthetic.
